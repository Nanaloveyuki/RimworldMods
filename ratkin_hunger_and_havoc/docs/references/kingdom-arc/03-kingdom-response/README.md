## 叙事

从一纸封簿公函走到施舍桌和护粮车。穗音以公主身份提出要求，别人照礼节接下，但她还得核对请求有没有办成。修订重点是让玩家看见她为何信任这些回应、何处产生怀疑，以及她仍愿意维护父母与王庭的部分；不能把她提前写成看透官场的旁观者。
