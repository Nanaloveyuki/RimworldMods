# K2-E1：两份回执

## 剧本

[背景图:两张抄件并列在桌面上，货号相同，日期栏与处理栏分开]
[手动阅读]
[发话:穗音，随件来信]

```text
两份抄件总算送到了。我把它们并排放好，货号相同，日期和处理栏却对不上。
```

[等待:玩家点击下一段；镜头移向两张纸的处理栏，移动0.6秒]

```text
请看货号下面那一栏。一份写着已经送到，另一份还在等准许出库。我对过日期，还是不明白同一批粮食怎么会有两种说法。
```

[等待:玩家点击下一段；沿用同图]

```text
我又去问了一次。对方说，也许是我抄错了。
```

[等待:玩家点击下一段]

```text
也许真是我抄错了。我从小觉得父亲最懂宫里的事，遇到不明白的，总想去问他。可这次我连两栏为什么不一样都说不清，也不知道该把问题带到谁面前。
```

[显示:选项；等待答复]

```text
正式询问配给厅
```

```text
私下联系当班书记
```

```text
不再追查
```

[条件:正式询问]
[背景图:穗音递交正式函件，对方收下并盖上收件章]
[等待1.5秒，随后手动阅读]
[发话:穗音，回信]

```text
他们收下问询了，你们的名字也记进了来函簿。

填过那一栏的书记已经被撤职。我想听听他怎么解释，再看看他说的能不能和纸上的字对上。
```

[条件:私下联系]
[背景图:信使在配给厅侧门外接过一封回信]
[等待1.5秒，随后手动阅读]

```text
书记答应谈一谈。他说自己已经不在配给厅办事，还请我别把信送到那里去。
```

[条件:停止]
[背景图:抄件仍在桌上，问询函没有封口]
[手动阅读]

```text
我先停下了。两份抄件请你们留着；现在我还不知道该从哪里继续问起。
```

## 流程与分支

正式与私下两种问询都接书记节点；停止直接到第二幕收束的未核验版本。信件可关闭后再答复，没有隐含阅读期限。日期差异只说明文书冲突，不证明贪污或实际库存短缺。
