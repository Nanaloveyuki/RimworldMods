# 认错亲人

## 来源场景

| 来源 ID | 场景 |
| --- | --- |
| I-033 | 认错亲人：把殖民者当成母亲的幼年鼠族来客 |
| I-047 | 鼠疫认错亲人：同类来客，在鼠疫开启时携带鼠疫 |

两条来源共用类开关、生成权重、到达态度设置、调试点数和长后续选择，目录缺省到达态度均为中立。穗音下信任小于零时再降一档。配置与抽取规则见 [事件目录](../incidents.md)。

## 当前流程

当前每次固定生成一只 RatkinYoung，不随事件点数增加，也不是旧背景所写的一群。默认使用 3 至 6.9 岁的幼年年龄范围；打开幼年跟随全局年龄范围后可以不同。到来正文按实际年龄选取：不满一岁不用孩子直接台词，满十四岁不用鼠蛋错音。

角色在地图边缘入场，建立访客 Lord，并打开认亲选择。玩家可永久接纳、俘虏、奴役、攻击、送往合格盟友、拒绝或忽视；每项仍看实际对象和相应闸门，奴役需要 Ideology。此类选择信不提供整批投喂、短工、长工按钮，右键通用处置见 [事件目录](../incidents.md)。没有收下也仍按来客寻食与离场规则行动，不能写成永远停在地图上。

认错不会建立原版 Parent 亲属关系。到来记录保存一个原图成年自由殖民者作为依附对象；当前一般生成入口没有传入“实际被喊的人”，因此回退选择人物 ID 最小的合格成年人。后续不会因玩家后来换养而改掉这个原对象。

I-047 保留实际鼠疫感染与传播，主事件信说明病情、治疗照料和传播风险；关闭鼠疫时说明健康到来。独立检疫、留观名单、结果计数与康复回访已退休。

## 后续

### 短后续

本类长后续默认关闭。短链由 ODF 按 `followPredatorPercent` 掷一次捕食者到来，默认 10%；选中且原批仍有合格猎物时才排入到来事件，处理后不重复投掷。手动开启长链后改用下述互动入口，不保证另附一次短链捕食者。

### 长后续：喊错之后还跟着

I-033、I-047 共用这条可手动开启的 ODF 通用链，不要求穗音。原孩子与原依附成年人都必须还活着。原孩子在原地图、属于玩家且已非婴儿时开始依附；这里不先等两年，也不要求鼠疫变体另过检疫节点。

孩子按实际工作追随照料者：饿到食物需求不足 50% 时尝试从对方背包取一份合适食物；夜间对方在床上时尝试在附近躺下；距离太远时尝试走近。无法行动、不可达、征召或正在进食等情况不强行覆盖任务。

| 选择 | 当前结果 |
| --- | --- |
| 继续给食物 | 足额检查并支付一份实际可用食物，清掉咬人心情；随后仍继续依附，选择间隔一天 |
| 停止给食物 | 固定一次 50% 咬人与 50% 取食分支；咬人对原依附成年人造成 3 点 Bite 伤害，孩子获得 +2 暂按永久保存的心情；取食分支执行就地吃一份食物，不离场 |
| 交给另一名成年人养 | 保存选中的真实照料者；第一次第二天返回原对象，第二次及以后改为依附新照料者 |
| 让它离开 | 生成一名成人接收者，将同一只原孩子交接离场；固定一次 50% 返访分支，十五天后检查 |

咬人后的 +2 在下一次选择投喂，或实际食物需求达到 90% 时移除。取食分支没有额外生成偷窃事件，也没有把孩子永久转为偷窃来客。

原孩子一直在家并达到 `followAdultAge`（默认 14 岁）时：换养不足两次，孩子 +4、原依附者 −2，均为 15 天；换养两次及以上，孩子 −6 永久，随后结案。医疗倒地暂停相应计时与追随工作。原孩子在成年前死亡，原依附者 −3、15 天；原依附者失效则链结束。原孩子成为囚犯或奴隶、或在依附阶段不再属于原图玩家时也结束，不以无关孩子续链。

离场后的返访只认原孩子：

- 没选中返访则结束；选中时必须原孩子已经离图且能实际带回。
- 生成两名成年来客，与带回的原孩子一起建立乞讨 Lord，并报告再次认人。
- 一天后全批离场、结案，不再开启第二轮依附，也不会再反复返访。

### 角色触发

成年心情独立于上述依附长链，生日检查达到 `followAdultAge` 时要求活着且本模组生命周期为 Released。数值受 `followMoodScalePercent` 影响，普通负面分支会尝试赋予善良特质；应用后保存一次性标记。

| 来源 | 普通角色各 50% 的结果 | 特质优先分支 |
| --- | --- | --- |
| I-033 | −5、15 天，或 +3、15 天 | 善良固定负面永久；心理变态或食人者固定正面永久 |
| I-047 | −6 永久，或 +3、15 天；另要求恢复鼠疫标记成立 | 善良固定负面永久；心理变态或食人者固定正面永久 |

I-047 的恢复判定当前读取 `!state.carriesPlague`，不是实际 Hediff 是否已消失。当前生成保存携带标记，未见康复清除此标记的运行路径，因此不能承诺治愈后必得这条成年心情。依附链中成年、换养与孩子死亡的结果由各自流程另行应用。

## 原设计与实现差异

本页吸收 I-033-01 与 I-047。换养一次回来、两次后换对象、真实咬伤、取食、带同一孩子返访及双方心情已有实现。当前初次来客只有一只，依附对象是保存的成年人回退选择，不是系统追踪某次喊话所得；不能添加真实亲子关系。旧文“按偷窃来客处理一次”在这里实际是就地进食工作。鼠疫变体也有同一长链，不沿用旧页“无长事件”。
