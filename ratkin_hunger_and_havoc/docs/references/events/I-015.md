# 难民接济

类配置键为 `I-015`。物资不同的接济请求归为一类；[难民接济（婴儿）](I-019.md) 只保留旧档流程，不在本类的新抽取中。

## 来源场景

| 来源 ID | 场景 |
| --- | --- |
| I-015 | 难民接济（简单餐） |
| I-016 | 难民接济（精致餐） |
| I-017 | 难民接济（药品） |
| I-018 | 难民接济（白银） |

## 当前流程

来客抵达后索取一批指定物资，种类、数量和答复期限写在请求信上。数量按财富、事件点数及 `requestPointScale` 求值，再夹在该物资的设置上下限内；答复期限读 `requestDays`，默认一天。

交付前核对足额库存，跨堆消费实际物品。不足时不部分扣费，也不结算成功。拒绝和超时按到达态度处理；忽视只关信，开放请求仍会超时。

穗音下，交付只把本批标记为已答应，不当场计入救济次数。活人全部离开原图，或在原地入籍、吃饱、无病地住满五天后才计一次。拒绝、超时、玩家直接杀死成员或最终没有活人均不算成功；详情见 [事件目录](../incidents.md)。

## 后续

本类没有交互长后续。短后续按 `followPredatorPercent` 掷一次野生捕食者。

### 救济成功后的角色心情

仅在本批实际计入救济成功时结算，未成功不触发。

| 来源 | 对象 | 随机结果 |
| --- | --- | --- |
| I-015 | 活着的成员 | 各 50%：`给了也能再要` +2，或 `袋子见底之前得再找一处` −2 |
| I-016 | 活着的成员 | 60%：`这次给的好` +4；40%：`好的会留到下次` −2 |
| I-017 | 结算时仍有伤病的成员 | 各 50%：`药够这一次` +3，或 `下次还是没有` −4 |
| I-018 | 活着的最年长成员 | 各 50%：`银子比饭轻` +3，或 `银子不能咬` −3 |

这些心情为临时心情。药品场景按救济结算时的伤病检查，不按交付时快照；健康同伴不触发。
