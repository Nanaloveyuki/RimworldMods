# 适配边界

- 第三方适配留在此处，基底 Visitor/Duty 不依赖具体模组；行为协作通过稳定快照、闸门、策略和事件接入
- 只消费对方公开 API，不反射私有组件、字段或滚动状态，不对其它模组私有类型打 Harmony；运行时查找公开 API 需缓存结果并核对签名
- 可选模组缺失、未启用或签名不兼容时给有界诊断并跳过适配；必需 HAR 异种许可失败则停止生成，不能套用可选联动的放行回退
- IrisMenus 注册与专用绘制一起受可选编译边界约束；绘制只画和裁剪可见内容，不保存设置或调用领域求值
- 牵引联动只走公开门面及本模组闸门，不接管对方 GameComponent；适配失败保持原访客职责，不凭未知调用结果记录成功
- 滚动与视口换算使用宿主公开坐标接口，重绘不触发设置保存；不能依赖私有宿主状态来恢复滚动或判断可见区域
