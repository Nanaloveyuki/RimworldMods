# 复合赋值

`let` 变量支持 `+=`、`-=`、`*=`、`/=` 和 `%=`。运算结果会写回当前作用域的变量：

```arti
let total = 0
for value in [1, 2, 3] {
    total += value
}
core.emit(total)
```

复合赋值要求左侧变量已经声明，`const` 变量不能修改。

## 多值接收和丢弃

```arti
fn result() { return true, "ready" }
let status, text = result()
status, _ = result()
```

`let` 声明新的变量；不带 `let` 时，除 `_` 外的目标必须是已有的可写变量。
`_` 表示丢弃对应值，可以重复使用，不会声明变量。`_ = result()` 丢弃整个结果。
丢弃值不会跳过函数执行或其中的副作用。

多值接收只支持 `=`，不支持成员、索引、嵌套目标或 `+=` 等复合赋值。
返回值必须是数量匹配的数组；多返回值函数会自动构造该数组。
右侧只求值一次，所有目标和数量检查通过后才写入，因此可以交换变量：

```arti
let a, b = 1, 2
a, b = b, a
```

数量不匹配或目标不可写时会报错，不会只更新部分目标；右侧求值已经产生的副作用不会回滚。
