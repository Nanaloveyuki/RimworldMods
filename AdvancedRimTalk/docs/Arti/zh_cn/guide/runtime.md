# runtime

Arti 在每次 Prompt 生成时作为一次性模板计算，动态数据也在这个阶段读取。

## 一次性函数

需要把写入常识库这类副作用限制成“每个世界一次”时，使用 [`core.once`](../core/once.md)。它在正式 Prompt 或 REPL 中执行无参函数，成功后把 id、时间、动作和说明写入 Mod 配置。之后相同 id 会被跳过，直到玩家在一次性记录页面删除该记录。

提示词预览会跳过 `core.once` 的函数体，也不会写记录。

## 一次执行

一次正式代码块执行的大致过程是：

1. 提取 `{{% ... %}}` 代码块；
2. 解析语法；
3. 检查名称、模块、作用域和控制流；
4. 创建当前生成的运行上下文；
5. 执行代码并收集输出；
6. 把输出放回原文位置。

解析或分析失败时，该代码块产出错误标记，并保留在生成结果中，方便定位。

## 限制

默认执行限制是：

| 限制 | 默认值 |
| --- | ---: |
| 最大执行步数 | `10000` |
| 最大函数调用深度 | `64` |
| 运行时错误是否写入结果 | 是 |

循环、表达式和函数调用都会消耗执行步数。超过限制会产生运行时错误。应限制查询集合、避免无界 `while`，并在输出前整理数据。

## 随机数

随机数来自当前 Prompt 执行上下文。同一次生成使用同一个随机源；跨生成的稳定值应来自游戏对象或会话状态。

## 动态数据

Pawn、地图、时间、天气、事件、聊天历史和 Mod 状态都在生成时读取。下一次生成可能得到不同结果。

## 只读边界

RimWorld 数据通过显式 provider、选择器和公开字段/属性读取。Arti 不执行任意方法，不访问文件、网络、程序集或私有字段，也没有修改游戏状态的内置 API。
