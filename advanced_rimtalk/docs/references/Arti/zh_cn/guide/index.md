# 使用指南

这一组页面说明 Arti 如何进入 RimTalk，以及遇到问题时应该看哪里。

- [start](start.md)：从第一个代码块开始。
- [document](document.md)：代码块边界、Markdown 围栏和多个代码块。
- [mode](mode.md)：嵌入模式与接管模式。
- [settings](settings.md)：相关设置项。
- [runtime](runtime.md)：生成时执行、步数和调用深度。
- [error](error.md)：解析、分析和运行时错误。

Arti 的语法和 API 分别在 [language](../language/index.md)、[global](../global/index.md)、[core](../core/index.md) 和 [data](../data/index.md)。
