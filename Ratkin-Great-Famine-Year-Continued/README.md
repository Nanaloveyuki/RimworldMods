# 鼠灾-大荒年 (Continued)

RimWorld 1.6 的“鼠灾-大荒年”延续维护版本。

## 当前改动

- 将大型流民冲击、大灾荒、鼠疫大灾荒和流民商队的大批 Pawn 生成分散到多个游戏 tick。
- 每个渲染帧最多生成一个 Pawn，降低事件触发时的单帧耗时峰值。
- 生成队列写入存档，完成后再统一建立队伍关系、Lord 与事件信件。
- 与原版包冲突时仅加载独立提示组件，阻止 Continued 的主体程序集、Def 与 Patch 重复加载。
- Mod 设置中提供可即时生效的新内容总开关；关闭后不再触发新事件或生成新 Pawn，已有 Pawn 及其工作逻辑继续运行。

原项目归属及维护授权状态见 [NOTICE](NOTICE)。

## IrisMenus 可选接入

启用 IrisMenus 时，设置分为十页：存档与卸载、事件频率与显示、环境自适应、角色行为、人物经历、捕食设置、原版事件、续作事件、结局控制、开发者。人物经历页可逐项启用事件生成鼠族的经历；角色行为集中放置寻食、咬尾巴、年龄、繁殖和特质设置；开发者页直接列出可触发的事件、剧情与结局预览，仅在开发者模式中提供操作。

IrisMenus 不是必需依赖；未安装时仍可使用完整设置。咬尾巴与新生儿身份继承归入普通角色设置，保持默认关闭。身份继承影响携带鼠灾基因的母亲所生的新生鼠族，不改变已有角色。

提供完整简体中文与英语文本。英语统一使用 Ratkin（鼠族）、Suin（穗音）、Guanyin clay（观音土）和 Ratkin young（鼠蛋）；游戏中的物资、疾病和身份沿用原版用语。

使用 PowerShell 7 运行 `scripts/verify-iris-menus.ps1` 验证可选检测、注册回调、分类分派、原页顺序和分类翻译。游戏内仍需验证分类切换、长页滚动、窗口缩放及关闭/重启后的设置持久化。

## 维护入口

### 鼠灾调度与进度设置

- 正面、负面事件分别独立抽取，通用设置中各自设置平均间隔（默认各 3 天，0 关闭该池）。这是每个合法事件目标上的随机平均间隔，不是固定倒计时；事件仍需满足原有触发条件。鼠灾不再混入原版随机事件池。
- 逐事件选择“对玩家正面/负面”，不改变来访者态度；默认按原事件正面信件归入正面池，其余归入负面池。
- 逐事件“可替代原版随机袭击”默认关闭。开启后，有可执行候选时替代随机袭击，另行参与独立池；替代不受两池间隔限制。排队与任务袭击不替代，执行失败保留原袭击。
- 穗音的鼠灾追踪警告直接显示信任值，即使没有未读事件也保留显示。
- 事件基准人数上限为 1～100，默认 30，成人、儿童、鼠蛋及动物合计。保留事件最低人数；上限过小时忽略限制，母子等固定组合除外。
- 求食访客的赈灾区食物评分默认额外提高 10%，可设置为 0～100%；仍综合距离和食物适宜性，不按选择概率解释。“事件鼠吃饱后离开”默认开启，每只鼠首次吃饱后独立随机停留设定值的 50%～150%；设定值为 0～5 天，默认半天。关闭离场开关不清除饱食历史。
- 普通事件生成年龄可设置为 0～100 岁内的区间，默认 0～50 岁；不兼容必要成长阶段时保留事件要求。鼠蛋、固定年龄和母亲等固定角色保留原年龄。自动检测 `cyanobot.toddlers`，缺少时仅为事件婴儿解除年龄性移动限制，不消除伤残、疼痛或意识导致的倒地。
- 易子而食、购买、收留及信件整批俘虏会清理事件牵引和宠物交易状态。弃婴交付逐只记录，已放下的鼠蛋离开赈灾区不会再次触发搬运。
- 找不到食物时可选择立即离开或等待，默认等待半天，等待时长为 0～5 天；期间定期重试，找到食物后重新计算后续断粮等待。
- 每次事件使用独立临时派系；商队不再因原版天气、温度或伤亡条件自动离场。收留、雇佣、弃婴交付、换子及剧情等待保留各自流程；收留到期的离场状态可保存并重试，倒地者不会直接消失。
- 虚拟“鼠族系”不再出现在基因权重和随机候选中，保留真实鼠族异种及其他子类型。
- 非穗音下的进度/信任计数与结局分别设置，默认均开启以保留既有行为。关闭计数保留已有进度，事件自身处理和发奖去重继续运行；关闭结局不影响事件处理。
- 切石机新增配方：任意 1 块石块（`StoneChunks`，不含钢渣）制作 3 份观音土。

新增验证：`scripts/verify-incident-scheduling.ps1`、`scripts/verify-narrative-settings.ps1`、`scripts/verify-feeding-summary.ps1`。这些使用引擎替身及结构检查；真实事件频率、警告布局、切石账单、离场 AI 和设置重启持久化仍需游戏内验收。

### 源码组织

- `1.6/Source/Utilities/`：按职责拆分的工具实现及共享函数；保留原类名与存档字段。

只验证、不部署：使用 PowerShell 7 运行 `scripts/verify-narrative.ps1`、`scripts/verify-pawn-components.ps1` 和 `scripts/verify-refactor.ps1`。静态检查不能替代游戏内存档、寻路和界面验证。

## 构建与部署

### 鼠难民屠杀与捕食

- `N-047 鼠难民屠杀`：有定居点的盟友优先发布，无盟友时使用中立派系；没有合适派系则不触发。接受后15天内杀死安居点全部原住民，获得12点好感；击倒或俘虏不算完成。任务可在续作事件分类中单独关闭。
- 安居点距事件所属据点随机4～8格，使用独立地图生成器：4间木屋、无炮台或电力设备，2～4名成年人和8～16名0～8岁鼠蛋。装备限低科技近战武器、木制短弓和部落装；鼠蛋不配武器。3岁以下无特质，其余使用现有坏特质池和既有原版/接入白名单。
- 续作事件设置中的“特殊情况：鼠难民被捕食”：每事件、每地图默认10%，可调0～100%；默认反击。无本地捕食者时出现“外边的捕食者”。关闭遵循存档难度时，外来捕食者饥饿且无可接近的鼠族或尸体便离图；开启时恢复原版觅食规则。居住区内鼠族尸体不可吃，已加入玩家的鼠族不作为此特殊情况的强制目标。
- 捕食状态随地图保存；活跃捕食者每250 tick最多搜索一次，空闲地图不扫描目标。“更强的敌人据点”的定居点生成入口不参与此独立 `Site`；尚需游戏内联用验收。
- 定向验证：`pwsh -NoProfile -File scripts/verify-refugee-events.ps1`。测试替身与构建不代替实际任务、寻路、存读档和Mod联用验收。

当前存档停用、卸载用副本导出及验证边界见 [存档停用与卸载](docs/recovery.md)。

逐事件态度设置、寻食缓存与性能验证边界见 [事件行为与性能](docs/event-behavior-performance.md)。

退出 RimWorld 后运行 `powershell -ExecutionPolicy Bypass -File .\scripts\build-and-deploy.ps1`，脚本会构建主体与冲突保护 DLL、同步运行所需文件并逐文件校验 SHA-256。
