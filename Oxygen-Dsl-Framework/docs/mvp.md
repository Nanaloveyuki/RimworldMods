# Oxygendsl 动态心情 MVP

## 目标

在同一个运行中的 RimWorld 1.6 存档里完成：新增玩法 → 观察 → 修改 → 再观察 → 撤销。首次加载框架程序集需要启动游戏；之后修改脚本不需要重启。本 MVP 验证降低 XML 接线和重启调试成本的闭环，已经完成。后续产品目标是逐步替代传统 XML Mod 的内容声明与修改，并扩展玩法规则，见 [后续需求解析](requirements.md)；不等同于替代全部 C# Mod。

本页先于实现落地，是本次功能与验收契约。完成状态只按实际验证证据更新。

标识契约：`packageId` 为 `nanaloveyuki.oxygendsl`，根命名空间为 `Oxygendsl`，程序集为 `Oxygendsl.Core.dll` 与 `Oxygendsl.Mod.dll`。持久类型使用 `Oxygendsl.Mod`，不保留旧名称别名。

## 功能范围

| 功能 | 语义 |
| --- | --- |
| 条件性持续心情 | 条件成立时存在，失效时移除；每条规则每个 Pawn 最多一个持续效果 |
| 限时心情记忆 | 条件成立时按冷却触发；明确选择刷新或有上限叠加；失效后已获得的记忆自然过期 |
| 内容定义 | 脚本直接定义稳定 ID、标签、描述、数值与持续时间，作者无需配套编写 ThoughtDef XML |
| 目标选择 | 当前地图殖民者 `colonists`、当前地图活着且有心情需求的 Pawn `map`、固定的选中对象 `selected` |
| 热更新 | 完整脚本验证成功后替换有效规则；修改错误保留上一份有效规则 |
| 应用与撤销 | 游戏内编辑、应用、立即评估、停用、重新启用；停用移除本脚本拥有的全部效果 |
| 运行检查 | 有效版本、规则、目标匹配、条件结果、跳过或错误原因、活动效果、上次 tick、耗时与可用分配数据 |
| 存档恢复 | 保存有效脚本、启用状态、固定选择、冷却截止时间、效果身份与记忆年龄；读档后不重复触发 |

`selected` 在首次需要它的应用时固定到当前选择的 Pawn；修改脚本不会意外改变已有固定选择，包括显式捕获的空选择，重新捕获选择是明确操作。当前地图切换或 Pawn 离开目标范围会撤销持续效果；限时记忆保留至过期。删除规则、改变规则类型、停用脚本会移除对应拥有的持续效果与记忆。规则不同 ID 即使标签相同也独立。

宿主管理一个可编辑主脚本文档，稳定规则 ID 在该文档内唯一；可导入活动 Mod 的 Oxygen 库。主脚本文本文件通过明确的重新读取操作应用，库模块在应用/读档时读取；不监视或自动执行尚未写完的文件。普通脚本不能任意访问文件或网络、反射、创建线程或操作 Harmony。

## 脚本写法

复用 Arti 的表达式、具名函数、控制流与命名参数，语言还支持后置类型约束、`struct`、普通组合/`embed`、类型化 list/array 和模块导入，完整语法见 [syntax-draft.md](syntax-draft.md)。语言核心独立于 RimTalk 与游戏程序集，来源按 MIT 条款注明；游戏宿主接口仍只有心情注册、只读 Pawn 和游戏上下文。

```text
fn at_night(pawn) {
    return game.hour >= 20 || game.hour < 6
}

mood("night_comfort",
    label: "夜晚安静",
    description: "夜里很安静。我可以歇一会儿。",
    offset: 5,
    target: "colonists",
    when: at_night)

memory("small_break",
    label: "稍作休息",
    description: "我歇了一会儿。现在感觉好多了。",
    offset: 3,
    target: "selected",
    duration: 2500,
    cooldown: 2500,
    mode: "refresh")
```

- `mood` 和 `memory` 的 `when` 可省略，省略表示目标合格即成立；存在时必须是接收一个 Pawn、返回布尔值的函数。
- `offset` 是有限心情点数，不是 0..1 的需求条百分比。
- 时间参数使用游戏 tick。暂停不推进持续时间或冷却；立即评估可在暂停时检查规则，不推进时间。
- `memory.mode` 为 `refresh` 或 `stack`；`stack` 必须给出正整数 `stack_limit`。冷却须为正整数，避免立即评估重复添加。
- 条件可读取 `pawn.id`、`pawn.name`、`pawn.mood`、`pawn.food`、`pawn.rest`、`pawn.drafted`、`pawn.downed`、`pawn.colonist`，以及 `game.tick`、目标所在地的 `game.hour`。
- 不存在的需求返回 `null`；条件作者可显式判断。已经死亡或没有心情需求的对象不获得效果，运行检查说明原因。
- 顶层 `let`／`const` 可配置注册参数，参数支持表达式；函数和控制流沿用 Arti。顶层可变变量是当前脚本实例的临时状态，重新应用或读档会重新初始化，不作为玩法存档字段使用。

## 热更新不变量

1. 同一 ID 更新原规则，不新增订阅或调度任务。
2. 解析、注册校验及候选目标条件评估全部成功后才切换有效规则；失败保留有效脚本和现有玩法。
3. 普通修改保持同一规则的记忆年龄和冷却截止时间。修改持续时间以原触发时刻计算，不隐式刷新；修改数值与显示内容更新现有效果。
4. 热更新缩小目标范围会清理不再匹配的持续效果。限时记忆不因条件变假而被删除。
5. 删除规则或停用脚本只删除带本框架归属与规则 ID 的效果，不按标签或共用 ThoughtDef 粗粒度删除。
6. 两条同名效果不能相互合并或删除；叠加上限按规则和 Pawn 计算，达到上限替换最早的记忆。热更新降低上限或改为刷新时，立即保留最新的允许数量，不等待下一次触发。
7. 周期评估中的错误不会继续使用不完整的目标结果来大规模删除效果；记录错误，下一次明确修改或评估仍可恢复。
8. 原版思想决定目标心情，当前心情条随原版机制逐渐趋近；不直接强制改写 `Need_Mood.CurLevel`。

## 界面

使用原版 Window、Widgets 与游戏字体，保留本机 UI 缩放；窗口按可用屏幕尺寸约束，不允许缩到控件互相覆盖。一个窗口：顶部有效状态与版本，中部脚本编辑与运行检查，底部错误与文件读取。主操作是“应用脚本”；“立即评估”“停用／启用”“重新捕获选择”“从文件读取”是分开的操作，显示文件路径与是否存在未应用修改。错误带行列、规则或对象，不只输出到日志。

入口为 Mod 设置中的“打开脚本窗口”；窗口进入地图后操作实际存档。提供中英文 Keyed。调试状态可通过 RimCarbon14 的真实对象读取与方法调用检查；不添加假的游戏状态或仅供测试的玩法分支。

## 当前 MVP 的运行与能力边界

默认每 150 tick 评估一次，界面可明确调整正整数间隔。应用及立即评估执行一次；不在每 Pawn 每 tick 解释脚本，不在每次评估重新解析。每次条件调用重置解释器步数与调用深度预算。空规则不枚举 Pawn。查询使用原版已存在的集合，复用计划与记忆查询缓冲区；只读上下文通过显式成员映射读取，不为每次调用复制成员字典。分配计数先做运行时校准，不支持或恒返回零时显示不可用。

动态心情 MVP 本身只支持这份契约的持久状态，不提供通用持久变量或 Job／WorkGiver；其后已加入原生 TraitDef／ThoughtDef 声明、修改与 Mod 规则入口，见 [当前语法](syntax-draft.md#原生内容与运行规则)。通用闭包序列化、任意方法拦截、LLM 自动执行脚本、分享平台或编译后端仍未提供。主脚本读档会重新读取模块并编译有效文本；依赖缺失或编译失败时停用并显示错误。

## 游戏内验收

全部使用隔离测试存档，不覆盖玩家原存档。RimCarbon14 已安装；通过真实 game、pawn、objects、ui、capture 和 profiling 工具验证。

| 编号 | 场景 | 可观察结果 |
| --- | --- | --- |
| A01 | 新建持续 +5 效果 | 需求页与真实思想对象显示新标签和 +5；不直接写心情条 |
| A02 | 同进程改为 +12 并修改标签／描述 | 对应效果更新，原条目不累积；进程实例不变 |
| A03 | 修改条件并立即评估 | 真假切换分别添加／移除持续效果；暂停时也可评估 |
| A04 | 全体殖民者改为固定选中 Pawn | 其他目标持续效果撤销；固定选择不会随 UI 临时选择漂移 |
| A05 | 连续应用同一脚本二十次 | 每规则每 Pawn 仍一个持续效果，单一调度入口；记忆冷却不重置 |
| A06 | 错误脚本及条件运行错误 | 有行列或规则／对象错误；上一份有效玩法不被清空 |
| A07 | 两条同标签不同 ID，再删除其中一条 | 另一条与原版思想保持不变 |
| A08 | 限时记忆刷新／叠加／到期 | 冷却约束生效，刷新不增条目，叠加不超上限，按游戏时间过期 |
| A09 | 有效果与未到期冷却时保存并读档 | 年龄、期限和固定对象恢复；不重复获得记忆 |
| A10 | 停用后重新启用 | 停用清理所有拥有的效果；启用重新评估，尊重保存的冷却 |
| A11 | 编辑窗口、按钮与需求页截图 | 实际绘制表面可读，操作结果与对象读取一致 |
| A12 | 删除全部规则 | 规则与活动效果归零；空运行时不扫描目标 |
