# 空投失误

## 来源场景

| 来源 ID | 场景 |
| --- | --- |
| I-032 | 空投失误：幼年鼠族通过原版空投舱落入地图 |
| I-046 | 鼠疫空投失误：同类空投，在鼠疫开启时携带鼠疫 |

两条来源共用类开关、生成权重、到达态度设置、调试点数和长后续选择，目录缺省到达态度均为中立。穗音下信任小于零时再降一档。配置与抽取规则见 [事件目录](../incidents.md)。

## 当前流程

执行时寻找地图贸易空投点，先生成原批角色、身份与访客 Lord，再把角色装入原版空投舱。人数按事件点数生成，使用 4 至 14 人的缩放范围及人数上限，不固定为几只刚出生的孩子。

空投使用独立年龄规则：80% 落在约一天大至 2.9 岁，20% 落在 3 至 6.9 岁。实际年龄决定婴儿照护和能否自行行走，不能把落地后的孩子都写成能自行爬出舱寻找食物。

来客选择开启时，玩家可以永久接纳、投喂、俘虏、奴役、攻击、送往合格盟友、拒绝或忽视；相应行为仍检查实际对象与闸门，奴役需要 Ideology。此类选择信不提供整批短工、长工按钮，右键单只来客的通用处置另按 [事件目录](../incidents.md) 执行。拒绝、超时和伤害按到达态度处理，忽视只关闭选择信；投喂不是直接写成吃饱。

I-046 保留实际鼠疫感染与传播。主事件信说明当前病情、治疗照料和传播风险，关闭鼠疫时说明健康到来；独立检疫、留观计数与康复回访已退休。

## 后续

### 短后续

本类长后续默认关闭。短链由 ODF 按 `followPredatorPercent` 掷一次捕食者到来，默认 10%；选中且本批仍有合格猎物时才排入到来事件，处理后不重复投掷。手动开启长链后改用互动入口，不保证另附一次短链捕食者。

### 长后续：来认空投的人

I-032、I-046 共用这条可手动开启的 ODF 通用后续，不要求穗音。初次到来记录原批孩子，长链等待 `followLongReturnYears`（默认两年，每年 60 天）后检查至少一只原孩子还活着、留在原地图并属于玩家。既有实例保留保存的期限。

随后生成一名真实成年鼠族，带一份布，并给焦点孩子保存一份真实布作为记物。来客自称孩子是被装错的，玩家可选：

| 选择 | 当前结果 |
| --- | --- |
| 对照布片 | 进入逐只选择，只有原批、仍在原图且属于玩家的活孩子可选；可以选择任意几只跟去，也可以全部留下 |
| 不对照 | 来客改口索取记录中的食物量（默认 6 份）；给或不给都会离开并结案 |
| 问孩子 | 来客离开，等待焦点孩子达到 `followAdultAge`（默认 14 岁），报告只记得落地后的饭，然后结案 |
| 让来客离开 | 来客离场；本批仍在原图属于玩家且已非婴儿的孩子获得 −2 心情，15 天，结案 |

交出孩子前核对原孩子、接收者、原地图与转移闸门；改变派系并离场，不能行走的孩子由合格成人携出。未选中的孩子保留原状；没有选中任何人也可直接结束。

交接成功后只以选中名单的第一只为返送对象，固定一次 50% 后续分支，十五天后检查：

- 未选中后续，或这只原孩子已死亡：结案。
- 选中后续且原孩子已经离开地图：发送缺粮返送选择。不要它回来则结案；要它回来则再等五天。
- 五天后把同一只原孩子带回原图，加入玩家并结束访客留驻，实际添加营养不良，食物需求降至 10%。当时已成年则另有 −6 心情，15 天，随后结案。

返送不会把所有送走孩子都带回，也不会生成替代孩子。不能从囚奴、另一张地图或玩家远行队中直接拉回；身份暂时不符合带回条件时等待。医疗倒地暂停相应期限，年龄不能行走不作医疗倒地。

### 角色触发

生日检查达到 `followAdultAge` 时，来源角色必须还活着且本模组生命周期为 Released；当前判定没有“从落地起从未离开或转手”的完整历史检查。数值受 `followMoodScalePercent` 影响，普通负面分支还会尝试赋予善良特质。

| 来源 | 普通角色各 50% 的结果 | 特质优先分支 |
| --- | --- | --- |
| I-032 | −3、15 天，或 +4、15 天 | 善良固定负面永久；心理变态或食人者固定正面永久 |
| I-046 | −6 永久，或 +2、15 天；另要求恢复鼠疫标记成立 | 善良固定负面永久；心理变态或食人者固定正面永久 |

I-046 的恢复判定当前读取 `!state.carriesPlague`，不是实际 Hediff 是否消失。当前生成保存携带标记，未见康复清除此标记的运行路径，因此不能承诺鼠疫治愈后必得这条成年心情。长链返送后的 −6 则由真实返送流程另行应用，不是这条成年规则。

## 原设计与实现差异

本页吸收 I-032-01 与 I-046。鼠疫变体现在也有同一长链，不沿用旧页“无长事件”。布片在后续来客生成时创建，当前没有核验初次空投舱上既存布料或建立真实亲属关系；“对布”是分支选择，不是物证匹配算法。返送只追踪第一只被选中的孩子，旧文“可能有一只送回”不能扩展为全部送回。连续留养历史和鼠疫康复心情也不能按旧设计作保证。
