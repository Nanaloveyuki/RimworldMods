# 商队劫掠

类配置键为 `I-035`。本类以玩家远行队为自然触发目标，是普通访客行为之外的袭击例外。

## 来源场景

| 来源 ID | 场景 |
| --- | --- |
| I-035 | 商队劫掠 |
| I-050 | 鼠疫商队劫掠 |

## 当前流程

鼠族袭击玩家远行队，生成原版商队遭遇地图并建立 `LordJob_AssaultColony`。人数按点数与人数上限生成。I-050 在鼠疫开启时实际携病。

到达与当前态度固定敌对，入场前锁定玩家和袭击派系的双向敌对关系，不使用类设置中的中立态度或穗音信任降档。袭击 Lord 保留偷窃、绑架且不超时撤退，不替换为访客离场 Lord。

成功建立袭击 Lord 后发送原版 ThreatBig 威胁信，定位实际袭击者；新遭遇地图通知原版敌对地图暂停。失败路径不发送袭击成功信。没有交粮即可和平结算的索取信，旧设计的“给够就散”不属于当前流程。

开发者“即时刷新”在当前选定地图边缘直接放置袭击者并建立同一袭击 Lord，刷新攻击目标缓存，不查找玩家远行队、不创建遭遇地图。自然触发仍以远行队为目标。

## 后续

本类没有交互长后续。既有短链定义仍保留；远行队站点不作为地图传入捕食者动作，因此自然劫掠不额外生成家园地图的捕食者。归属及调试规则见 [事件目录](../incidents.md)。
