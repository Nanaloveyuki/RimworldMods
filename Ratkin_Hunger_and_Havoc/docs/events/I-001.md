# 乞讨队伍

类配置键为 `I-001`。同类场景共用开关、生成权重、到达态度、调试点和后续选择；抽取规则见 [事件目录](../incidents.md)。

## 来源场景

| 来源 ID | 场景 |
| --- | --- |
| I-001 | 大批逃难者 |
| I-005 | 乞讨的鼠族队伍 |
| I-042 | 鼠疫乞讨队伍 |

## 当前流程

饥饿的鼠族进入家园，向殖民者乞讨食物。I-001 是较大规模的逃难队伍；I-005 是普通乞讨队伍；I-042 保留同类访客行为，鼠疫开启时实际携病。人数按具体场景的点数规则和人数上限生成，不因合并而统一成相同规模。

来客使用访客 Lord，先前往居住区外可达的停留点，再执行乞讨、取食和离场。可用食物和行动由赈灾区、角色闸门与玩家设置决定；吃饱后的停留和断粮等待沿用访客期限。

I-005、I-042 可以打开整批来客选择信，提供投喂、收留、短工、长工等符合当前状态的选项。I-001 当前没有整批选择信，不因归入本类自动获得相同按钮；仍可按具体来客处理。投喂按人交食，收到食物不等于已经吃饱。

拒绝、超时、驱逐与玩家伤害的态度变化见 [事件目录](../incidents.md)。鼠疫病情和传播提示并入主事件信，没有独立检疫、留观或康复回访。

## 后续

本类没有交互长后续。短后续按 `followPredatorPercent` 掷一次野生捕食者；选中后延迟 120 tick 到达，不重复投掷。
