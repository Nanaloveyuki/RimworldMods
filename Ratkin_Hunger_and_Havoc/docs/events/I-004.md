# 乞讨的母亲

## 来源场景

| 来源 ID | 场景 |
| --- | --- |
| I-004 | 一位母亲带着原孩子到来求食 |

本类单独保存事件开关、生成权重、到达态度、调试点和长后续选择。缺省到达态度为偏友好；穗音信任为负时再降一档。抽取和通用处置见 [事件目录](../incidents.md)。

## 当前流程

当前固定生成三人：第一名为女性乞讨母亲，另两名为她的乞讨孩子，并保存母亲与孩子的身份引用。这一家不随点数扩大，也不按普通人数上限拆散。旧背景中的“四个鼠蛋”不是当前固定人数；主事件信读取实际孩子数。

母亲和孩子进入访客寻食、乞讨流程。母亲分食开关开启时，若她库存有可吃的食物、原孩子饥饿且可接近，母亲会给孩子一件实际食物，放进孩子库存或放在附近；这不直接把孩子写成吃饱，也不保证每次都是母亲最后才吃。

来信提供以下选择，实际可执行对象受身份、病情和行为闸门限制：

| 选择 | 当前处理 |
| --- | --- |
| 短工 | 合格成员暂入玩家派系；期限读设置，默认五天 |
| 永久加入 | 合格成员永久加入，清除临时停留期限 |
| 长工 | 合格成员暂入玩家派系；期限读设置，默认一年，一年按 60 天 |
| 投喂 | 为每名合格成员分别建立交食等待；各人索取自己的份数，只有实际吃到阈值才算吃饱 |
| 拘捕、奴役 | 处理实际合格的成员；奴役需要 Ideology |
| 攻击、送往盟友 | 攻击是显式敌对动作；转交需要可用盟友和转移许可 |
| 拒绝、忽视、暂缓 | 拒绝按当前到达态度处理；忽视只关闭本封信，暂缓仍受原期限限制 |

答复期限读 `requestDays`，默认一天；中立拒绝或超时离开，不转敌对。短工、长工到期恢复当前态度的访客派系并离开，同批共用照护流程；医疗倒地暂停计时，健康婴儿仅因年龄不能行走继续计时，需要时由合格成人携出。单人右键与赈灾取食规则见 [访客代码](../../Source/Pawn/)。

## 后续

### 短后续

当前走 ODF 短后续，对本批在场角色投掷一次捕食者到达概率，默认 10%，可配置；抽中且仍有本批猎物时安排到达，之后不重复投掷。

### 长后续

没有登记互动长后续。此类不属于默认开启长后续的两类，选择长后续也不会生成另一条母亲返访链。

### 角色触发与穗音记录

当前没有接入本事件专属的成年回忆。母亲分食、孩子实际进食、加入、囚禁和离场沿用通用角色流程。

穗音下的观察与救济记录仍按本批事实处理：普通观察在 IrisMenus 主动查看，不再自动发送 Journal 复述；救济成功不能由“已答应”或投喂按钮直接替代。批次成功、失败与信任规则见 [事件目录](../incidents.md)。这些记录不是 ODF 长后续，也没有本事件专属托孤选择。

### 原设计 / 尚未接入

`OnStarvedChild` 保留了母亲对乞讨孩子饿死的心情规则：普通母亲 50%“我带出来的那只没吃上”−6、15 天，50%“少一张嘴”+3、15 天；善良固定前者且永久，心理变态或食人者固定后者且永久。

当前没有死亡或饥饿通知调用该规则，也没有把“乞讨期间饿死”的事实送入此方法。不能将旧页这组母亲心情写成当前会自动触发的结果；吃饱离开、驱逐或孩子成年也没有接入另一组本事件心情。
