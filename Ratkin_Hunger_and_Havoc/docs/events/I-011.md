# 请求收留的逃难者

类配置键为 `I-011`。同类配置与抽取规则见 [事件目录](../incidents.md)。

## 来源场景

| 来源 ID | 场景 |
| --- | --- |
| I-011 | 灾荒逃难者 |
| I-040 | 鼠疫逃难者 |

## 当前流程

逃难鼠族来到家园，请求留下。I-040 是携带鼠疫的变体；关闭鼠疫时健康到来，不开启独立检疫链。

生成后打开请求收留的选择信。玩家可按当前状态永久收留、接纳为短工、雇佣为长工、投喂、拒绝或选择其它有效处置。短工和长工到期恢复来客派系并离开，医疗倒地暂停期限，单纯因年龄不能行走不暂停；永久加入清除临时期限。

未加入者仍由访客 Lord 管理，前往居住区外可达的停留点。投喂逐人等待实际交食，再以实际进食判断吃饱。拒绝和超时按到达态度处理，不一律转敌对。鼠疫来客使用原事件的处置选项，病情、照料需求和传播风险写在主事件信中。

穗音下，答应接纳或投喂只标记本批已答应。救济成功须等活着的成员全部离开原图，或在原地入籍、吃饱、无病地住满五天；玩家直接杀死任意一人会使整批失败。完整条件见 [事件目录](../incidents.md)。

## 后续

本类没有交互长后续。短后续按 `followPredatorPercent` 掷一次野生捕食者。
