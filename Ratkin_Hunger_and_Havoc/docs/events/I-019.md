# 难民接济（婴儿）

## 来源场景

| 来源 ID | 场景 |
| --- | --- |
| I-019 | 难民接济（婴儿）：保留旧档已有请求、原孩子身份及后续 |

I-019 不在 `RHAH_IncidentGroups` 的二十类中，非第二十一类，也不并入仍活动的“难民接济”类。它不再参加自然抽取、广播或新的调试触发；旧队列、已有开放请求和后续记录仍保留原来源 ID。现行难民接济入口见 [I-015](I-015.md)，目录与旧档规则见 [事件目录](../incidents.md)。

## 当前流程

本页说明兼容保留的旧请求，不是新开局可抽到的玩法。已有信保留原地图、原来客、金额字段与期限，同一开放请求不会重开一封。关闭选择功能也不阻止已有请求到期结算。

旧请求分别提供实际玩家孩子名单和简单餐替代选项，不共用一个交付按钮：

- 只能选择原地图上已生成、活着、属于玩家的自由人类角色，生物年龄小于十四岁；不能是囚犯、奴隶或医疗倒地，来源角色还须允许转移。因此沿用“婴儿”旧名称，但实际名单不限于婴儿，不再要求囚犯或奴隶婴儿。
- 玩家明确选择一名孩子后，交接前重新检查请求仍开放、原来客及派系还可用、孩子仍合格，以及模组来源角色的交接权限。因年龄不能行走的健康婴儿不视为医疗倒地。
- 成功后，所选的同一只孩子改为来客派系并离图，作为世界 Pawn 保留；记录保存真实孩子 ID 与负责成年人的 ID。原批来客进入离场流程。
- I-019 可用简单餐代替交出孩子，沿用 `childExchangeFoodSubstitution` 开关；成本为 `foodPerChild` 的两倍，默认 20 份，不按来客人数增加。食物选项显示实际份数，不要求殖民地有孩子；孩子选项不要求粮食。关闭替代仅禁用食物选项。食物成交不交出玩家孩子，也没有 I-013 的来客孩子交换加入，不触发交出孩子的心情或返访长链。
- 可以拒绝、忽视或暂缓；超时读已有期限。拒绝和超时沿用本批到达态度处理，忽视只关闭信。交付只记下已答应，救济最终计数仍按 [事件目录](../incidents.md) 的实际离图或安置条件，不在点按钮时直接计成功。

## 后续

### 已有短后续

已有 ODF 短链仍按保存阶段继续。阶段 0 按 `followPredatorPercent` 掷一次捕食者到来，默认 10%；原批没有合格猎物时不生成，处理后不重复投掷。已结束实例不重开。

### 已有长后续：被要走的那个

I-019 没有新的类长链设置，也不属于默认开启长后续的两类。本节只处理旧档已经保存的长链；它是 ODF 通用后续，不要求穗音。未结束的旧阶段 1 会转到互动阶段 3，原期限移入 `dueTick`，保留实例、原人物与原地图。

必须已经保存真实交出孩子和离场身份；原孩子还活着、不再是婴儿、已到保存期限，并且能够带回原地图时才返访。这里不要求先活到十四岁。孩子若在别图、商队或其它持有者中，或仍为囚奴，不能远程拉回；历史记录没有真实交出孩子身份时，到期结束，不随机找一个殖民者冒充。

返访使用同一只孩子，玩家可以：

| 选择 | 当前结果 |
| --- | --- |
| 让它进来并给食物 | 足额检查并支付记录食物量（默认 6 份），进入指出当年交出者的选择；这一步不自动把返访孩子加入玩家派系 |
| 指出一名成年人 | 从原图成年自由殖民者中明确选择，被指出者 −8 永久心情，孩子 +2、15 天；三天后继续问去向 |
| 不指出 | 固定一次 50% 认错分支；认错时选原图人物 ID 最小的合格成年人，给对方 −3、15 天；一天后报告认不出，再等两天继续问去向 |
| 不让进 | 等到当地当日结束时，尝试偷取可达食物离场；实际离图后十五天再试一次返访，最多重来一次 |
| 俘虏来客 | 按实际来客俘虏，三天后进入去向阶段；以后若真实交易再次卖出，孩子 −10 永久心情，链结束 |

偷食会寻找实际可达、可预留、非尸体食物，执行携食离场工作，最多取六件；没有合格食物则尝试直接离场，不能保证偷窃成功。拒绝后第二次离图即结案，不循环生成第三只孩子。

孩子留在原图到下一阶段后可以选择等下一批难民询问。当前依赖到来通知接受同图 I-019 或 I-040 来源，而不仅是旧文的“下一批要婴儿的难民”；I-019 不再新抽取，I-040 仍可唤醒已有后续。来客到来时固定一次 50% 承认见过或否认分支：

- 承认时可以支付记录食物量换去向，或不再追问；是否对得上由返访时已经保存的分支决定，消息发出后结案。
- 否认时只有停止追问，结案。
- 等待来客不会额外生成一支 I-019 队伍。原孩子死亡或相关身份失效时按已有流程结束。

心情、再访次数、被指出的人、去向分支、交接身份及期限保存在 `longFollows`。医疗倒地暂停相应期限；年龄导致不能行走不作为医疗倒地。

### 角色触发与标记限制

成年规则仍保留 I-019 来源且带 `rhah:gave` 标记的角色：在生日检查达到 `followAdultAge`（默认 14 岁）、还活着且没有已应用标记时，普通角色各 50% 得到 −8 永久或 +4、15 天心情；善良固定负面永久，心理变态或食人者固定正面永久。普通负面分支还会尝试赋予善良，数值受 `followMoodScalePercent` 影响。

这不是“交出的真实孩子到十四岁必有心情”的承诺。当前 `OnChoice` 把 `rhah:gave` 写给原请求 `PawnLoadIds` 中的来客，真实孩子交接只保存其 ID，没有给该孩子重写 I-019 来源及此标记。因此返访孩子只有原本就符合来源与标记条件才会得到这条成年结果；长链中指出、认错、再次卖出产生的心情则直接作用于已保存的人物，不依赖这条成年标记。

## 原设计与实现差异

本页吸收 I-019-01。真实孩子选择、真实返访、指出或认错、拒绝后最多再来一次、俘虏与再次卖出、向后来的难民询问去向已有实现。旧文要求囚奴婴儿、必等十四岁返访、只问下一支婴儿请求队伍，以及把交出孩子的专属成年心情视为已接通，均不作为当前流程。

核对入口：`RHAH_IncidentGroups`、`ChoiceLetter_RHAH_Request`、`RHAH_ChildExchange`、`RHAH_ChoiceRuntime`、`RHAH_LongAdoptionFollow`、`RHAH_LongFollowRuntime`、`RHAH_LongFollowRecord`、`RHAH_EventFollowRules`、`RHAH_EventFollowMood`。旧档身份缺失与退休节点迁移见 [存档归属](../save-ownership.md)。
