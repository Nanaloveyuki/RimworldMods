# 遗弃幼年鼠族

## 来源场景

| 来源 ID | 场景 |
| --- | --- |
| I-002 | 幼年鼠族遗弃：孩子被留下，原母亲不在地图上 |
| I-037 | 鼠疫遗弃幼年鼠族：留下的孩子和原母亲按鼠疫开关生成病情 |

本类共用事件开关、生成权重、到达态度配置、调试点和长后续选择；未配置态度时，I-002 缺省偏友好，I-037 缺省中立。穗音信任为负时，到达态度再降一档。抽取和通用处置见 [事件目录](../incidents.md)。

## 当前流程

- I-002 的孩子人数随事件点数变化，原始范围为 1–10 人，再受人数上限约束；I-037 当前为单个孩子。默认使用低龄乞讨孩子的年龄范围，开启幼年年龄跟随配置后以实际生成年龄为准。
- 初次到来就建立一位真实女性母亲，将她作为世界角色保留，并给原孩子建立亲子关系和身份引用。地图上到来的仍是被留下的孩子，不演出母亲带队、放下后离开的整段动作。以后返访用这位原母亲，不临时生成另一位来冒充。
- 孩子进入访客流程。来信可选择永久加入、拘捕、奴役（需要 Ideology）、攻击、送往可用盟友、拒绝、忽视或暂缓；加入、囚禁和转移等选项受实际角色闸门限制。本类到来信没有整批短工、长工或投喂按钮，单人处置以 [访客代码](../../Source/Pawn/) 为准。
- 答复期限读 `requestDays`，默认一天。拒绝与超时按到达后的态度处理；中立离开，不自动转敌对。忽视关闭本封选择信，不等于驱逐。
- I-037 的鼠疫病情、治疗照料与传播风险并入主事件信；关闭鼠疫时使用健康到来的说明。没有独立检疫链，也没有检疫结果、康复回访或留观倒计时。

## 后续

### 短后续

本类长后续默认开启。改选短后续后，由 ODF 对本批在场角色投掷一次捕食者到达概率，默认 10%，可配置；抽中且仍有本批猎物时安排捕食者到达。短阶段处理后停驻，不反复投掷。

### 长后续

这是 ODF 通用事件后续，不要求当前叙事者是穗音。I-002 与 I-037 共用开关，但保留各自的返访条件与选择；选择长阶段后，不另投同一条短阶段捕食概率。既有后续不会因修改默认配置重新开始。医疗倒地暂停相应期限；婴儿仅因年龄不能行走不算医疗倒地。

#### I-002：原母亲回来认孩子

初次事件后经过长返访间隔（`followLongReturnYears`，默认两年，一年按 60 天），至少一名原孩子仍活着、在原地图属于玩家且达到后续成年年龄（`followAdultAge`，默认 14 岁），原母亲也还活着，才进入认亲。尚未长大时继续等待，不用无关孩子替补。

母亲回到地图边缘，选中一名合格原孩子，不进入殖民地寻食；其余孩子不逐个认领。

| 选择或情况 | 当前结果 |
| --- | --- |
| 让她见选中的孩子 | 实际安排边缘会面，固定随机抽取平静或愤怒回应；会面后再问是否让这名孩子跟她走 |
| 允许带走 | 核对孩子身份、转移许可与医疗状态，转为母亲派系并实际离场 |
| 见面后留下孩子，或带走答复超时 | 母亲离开，获得“来了也不领”−3 心情，15 天 |
| 不让见，或认亲答复超时 | 孩子获得“麻麻在外面”−2 心情，15 天；母亲再等一天后离开 |
| 给食物让她走 | 足额交出记录要求的食物（新记录为 6 件），母亲离开，结束认亲 |
| 母亲伤病或饥饿倒地 | 可以留她治疗，或选择暂不治疗；留治到不再医疗倒地后回到原选择，不直接变成加入 |
| 母亲在此次原地图返访中死亡 | 选中的原孩子活着且达到后续成年年龄时，获得“麻麻死在门口”−6 永久心情 |

允许带走后，离场时已固定的 50% 分支可能在母子都能返访时让两人再次回来乞讨；等待间隔读 `followMotherReturnDays`，默认 15 天。此时只能给食物或拒绝，答复默认一天，之后母子离开；不再认第二名孩子。

#### I-037：病着离开的原母亲

返访间隔读 `followMotherReturnDays`，默认 15 天；不要求孩子先成年。原母亲活着，且记录能确定原孩子在原地图玩家一侧、已经死亡或已经转出时，才进入对应分支；孩子去向暂时不明时等待。

| 原孩子的情况 | 当前选择和结果 |
| --- | --- |
| 仍活着并在玩家一侧 | 实际安排边缘会面。见到后可让母亲离开，或把她叫住；默认当天离开，至少留出一小时答复 |
| 叫住母亲 | 可给食物和药物（新记录为 6 件食物、2 件药物），她再留一天后离开；不给则离开。结束这次探望时母亲获得“还活着就行”+2 心情，15 天 |
| 原孩子死亡 | 可回答埋葬情况，读取原孩子尸体是否在墓中；不回答则等到当地 18 时离开。没有复活或换一个孩子的选择 |
| 原孩子被卖掉或送走 | 母亲听完离开；经过返访间隔，另来两名成年鼠族询问去向。说出则离开；隐瞒或一天答复超时则尝试偷取实际可拿的食物后离开 |
| 母亲仍有伤病 | 可留治，直到伤病消除且不再医疗倒地，再返回孩子情况对应的选择；治疗本身不使她加入 |

看过仍活着的孩子后结束这条探望，不安排母亲第三次回来。询问孩子去向的两名来客不是原母亲的替身。

### 角色触发

成年心情走角色生物学生日通知，达到 `followAdultAge` 后首次满足条件时结算一次；与长后续开关、穗音专属节点无关。以下为默认心情数值，成对成年心情受后续心情倍率设置影响。

| 来源及条件 | 普通角色的 50% / 50% 结果 | 特质覆盖 |
| --- | --- | --- |
| I-002，原母亲不在孩子所在地图 | “麻麻把窝放在介,然后木有惹”−4，15 天；或“麻麻走惹,窝次饱惹”+6，15 天 | 善良固定前者且永久；心理变态或食人者固定后者且永久 |
| I-037，身份的 `carriesPlague` 为 false，原母亲已死或不可找到 | “麻麻把窝放惹,麻麻洗惹”−6，永久；或“麻麻洗惹,窝木有”+4，15 天 | 善良固定前者且永久；心理变态或食人者固定后者且永久 |
| I-037，身份的 `carriesPlague` 为 false，原母亲活着 | “麻麻把病病也留下惹”−4，永久；或“活下来惹”+3，15 天 | 善良固定前者且永久；心理变态或食人者固定后者且永久 |

死亡的孩子不结算成年心情。I-002 普通负分支还会授予善良特质；已有善良者不会重复获得同一特质。

I-037 的上述成年条件目前读取来源身份的 `carriesPlague`，不是实际鼠疫是否康复。新鼠疫来源将该值保存为 true，当前没有康复后清除此值的调用；因此不能承诺新 I-037 孩子治好病后就会自动得到这组成年心情。即使关闭鼠疫、角色实际健康，这个来源标记也不会由病情开关自动清除。身份值为 false 的旧记录才可能满足这项条件；原母亲死亡分支的普通负结果还会授予善良。

### 穗音专属记录与实现边界

普通观察与救济批次仍保存，记录在 IrisMenus 主动查看，不再自动发送 Journal 或托孤到来复述；救济成功条件见 [事件目录](../incidents.md)。这些记录不替代上面的 ODF 原母亲返访。

I-037 另有穗音 N-004 托孤规则，但当前 `RHAH_EntrustCare.OpenEntrust` 只从本封到来信的成员中寻找成年母亲与孩子，没有读取世界原母亲。当前单个遗弃孩子场景不满足这项开案条件，不能把世界原母亲写成已可操作的穗音托孤来客。旧档已有托孤记录仍按其自身规则处理。

旧档若没有保存原母亲身份，长后续结束，不随机补一位母亲；保留过的原孩子与亲子引用才可恢复。
