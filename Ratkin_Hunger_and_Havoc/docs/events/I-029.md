# 待产流民

## 来源场景

| 来源 ID | 场景 |
| --- | --- |
| I-029 | 待产流民：进入分娩流程的女性鼠族来客 |
| I-044 | 鼠疫待产流民：同样进入分娩流程，来客按鼠疫开关携带病情 |

本类共用事件开关、生成权重、到达态度配置、调试点和长后续选择。未配置态度时，两种来源均为中立；穗音信任为负时再降一档。抽取和通用处置见 [事件目录](../incidents.md)。

## 当前流程

- 两种来源当前都固定生成两名女性乞讨母亲角色，不随点数扩大，也不按普通人数上限拆散这一批。
- 启用 Biotech 且可用原版怀孕定义时，生成过程为母亲建立怀孕与真实生母关系并启动分娩。分娩结果、孩子存活、实际人数和后续照护由真实生产流程决定，不保证每名母亲必定生下活婴儿；没有 Biotech 时不会启动这段怀孕、分娩实现。
- I-044 的病情实际施加给生成来客，不能仅凭来源 ID 就宣称每个新生儿必定带病。主事件信追加鼠疫病情、治疗照料和传播风险；关闭鼠疫时显示健康到来的说明。没有独立检疫链、检疫留观或康复回访。
- 来客进入访客寻食、乞讨流程。母亲与实际新生儿的生产关系保留，不另生成无关孩子替代原孩子。

来信提供以下处置，按钮与实际合格成员受角色身份、当前病情和行为闸门限制：

| 选择 | 当前处理 |
| --- | --- |
| 短工、永久加入、长工 | 对实际合格成员执行；短工默认五天，长工默认一年，永久加入清临时期限，期限均读设置 |
| 投喂 | 对每名合格成员分别建立交食等待，各自收到食物后仍需实际进食达到阈值 |
| 拘捕、奴役 | 转为实际囚犯或奴隶；奴役需要 Ideology |
| 攻击、送往盟友 | 攻击为显式敌对动作；转交需要可用盟友和转移许可 |
| 拒绝、忽视、暂缓 | 拒绝按到达后的态度处理；忽视关闭本封信；暂缓仍受原期限限制 |

答复期限读 `requestDays`，默认一天。缺省中立拒绝、超时离开，不自动转敌对。短工、长工到期恢复当前态度访客派系并离开；医疗倒地暂停期限，婴儿只因年龄不能行走继续计时，不能自走者按通用照护和携出规则处理。出生后不会自动把所有新生儿补入最初选择信的成员名单。单人处置与孩子照护见 [访客代码](../../Source/Pawn/)。

## 后续

### 短后续

两种来源当前只有 ODF 短后续：对本批在场角色投掷一次捕食者到达概率，默认 10%，可配置；抽中且仍有本批猎物时安排到达，之后不重复投掷。

### 长后续

没有登记互动长后续。本类不属于默认开启长后续的两类；配置选择长后续也不会产生另一条生产观察或母亲重访链。

### 角色触发

原版生产结果返回实际母亲和婴儿时，出生通知记录这位母亲的出生时间与这个婴儿身份。I-044 若该婴儿在出生通知时已有实际鼠疫，调用母亲心情“生下来就带着”−6、15 天。此调用发生在出生通知，不是之后任何时候感染都自动补发；母亲后续死亡也没有另一条本事件结果。

本类没有接入孩子成年后的专属出生回忆。普通角色变化、鼠疫感染传播与死亡仍沿用真实角色流程，不因缺少观察后续而停止。

### 原设计 / 尚未接入

源码保留了出生观察规则和对应设置，但目前未找到消费出生时间、原婴儿身份并延迟结算的运行时入口。下表是已有规则，不是当前已经自动执行的三天、五天观察链：

| 来源 | 保留的规则 |
| --- | --- |
| I-029 | 母亲与所记孩子都活着，达到 `followBirthWatchDays`（默认三天）：50%“又多了一张嘴”−4、15 天，50%“生下来了”+2、15 天；善良固定后者，心理变态固定前者 |
| I-044 | 母亲活着，所记孩子活着且无鼠疫，达到 `followPlagueBirthDays`（默认五天）：50%“这只还没染上”+3、15 天，50%“下一只不一定”−3、15 天；现有规则中善良固定后者、心理变态固定前者 |
| I-044 的病儿分支 | 规则可在孩子有病且母亲活着时给“生下来就带着”−6、15 天；当前实际接入点仅为上面的出生通知 |

原页中“任意孩子出生后三／五天自动给母亲心情”和“以后染上鼠疫，无论死活都立即补发”不写作当前事实。出生记录当前只存最近通知的一个婴儿，也不是逐个保存整窝孩子的观察名单。

### 穗音记录

本批普通观察与救济事实仍保存，在 IrisMenus 主动查看；不再自动发送 Journal 复述。救济成功、失败和信任依 [事件目录](../incidents.md) 的通用批次规则处理，不以开始分娩、答应加入或孩子出生替代救济完成。本类没有专属穗音检疫、托孤或交换照料链。
