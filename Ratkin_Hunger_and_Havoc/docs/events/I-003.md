# 耗子分妈

## 来源场景

| 来源 ID | 场景 |
| --- | --- |
| I-003 | 孩子啃食过母亲后，一位重伤母亲与原孩子一起到来 |

本类单独保存事件开关、生成权重、到达态度、调试点和长后续选择。缺省到达态度为偏友好；穗音信任为负时再降一档。通用抽取和态度规则见 [事件目录](../incidents.md)。

## 当前流程

- 第一名角色是女性母亲，其后为孩子；总人数随点数变化，为一位母亲加 1–10 名孩子，不按普通人数上限拆散这一家。
- 到来前给母亲施加缺失左耳、右腿、鼠尾的伤残，并将失血严重度至少设为 0.7。缺失部位以实际身体结构能找到的部位为准。旧背景中的啃食已经表现为母亲的伤病，不在到来时重新演出孩子逐口攻击，也不逐个强制把孩子标成吃饱。
- 本批建立母亲与孩子的身份引用，成年心情按这位母亲的真实存活情况分支。孩子默认使用 3–6.9 岁范围；年龄跟随配置开启时以实际生成年龄为准。
- 本批进入访客 Lord，抵达停留点后寻食，不再采用旧设计的“横穿地图直接离开、不停留”。伤病救治沿用实际医疗流程。
- 来信使用遗弃类处置：永久加入、拘捕、奴役（需要 Ideology）、攻击、送往可用盟友、拒绝、忽视或暂缓；按钮受实际角色闸门限制。本封信没有整批短工、长工或投喂按钮。单人处置和母亲给饥饿原孩子分食的规则见 [访客代码](../../Source/Pawn/)。
- 答复期限读 `requestDays`，默认一天。拒绝、超时按到达后的态度处理；忽视只关闭本封选择信。不能因事件背景就视为一家已经安置或已经救济成功。

## 后续

### 短后续

当前只有 ODF 短后续：对本批在场角色投掷一次捕食者到达概率，默认 10%，可配置；抽中且仍有本批猎物时安排到达。处理后不重复投掷。

### 长后续

没有登记互动长后续。即使配置中选择长后续，本来源也仍走短阶段，不生成原母亲认亲、换子或复访。

### 角色触发

达到后续成年年龄（`followAdultAge`，默认 14 岁）后，在首次满足条件的生物学生日通知中按本批母亲是否活着结算一次。当前规则没有限定只让孩子角色结算；同来源角色若也满足年龄与未结算条件，会进入相同规则。

以下为默认数值，受成对成年心情倍率设置影响：

| 母亲情况 | 普通角色的 50% / 50% 结果 |
| --- | --- |
| 已死或无法找到 | “窝滴妈妈被窝次了,窝好愧疚叽...”−6 永久心情，并获得善良；或“窝滴妈妈被窝次了,饿饿就次天经地义吱!”+12 心情，15 天，并获得食人者 |
| 活着 | “窝对不起窝滴妈妈”−3 永久心情，并获得善良；或“饿饿就次次叽!泥看窝滴妈妈还活滴好好滴!”+24 心情，15 天，并获得食人者 |

已有善良者固定负分支且永久；心理变态或食人者固定正分支且永久，并尝试授予食人者。同一特质不会重复授予。母亲活着时当前善良负分支仍是 −3，不是旧页写的 −6。

### 原设计 / 尚未接入

- `OnChildDeath` 保留了“原孩子未满 14 岁死亡、母亲还活着”时的母亲心情规则：50% +3 永久，50% −3、15 天。当前死亡通知只更新生命周期、访客组和长后续，没有调用此规则，因此不列作已自动发生的角色触发。
- 旧页列出的十一项囚禁、奴役随机心情没有当前事件运行时的调用证据。囚禁、奴役本身仍可执行，身份与后果沿用通用角色流程，不承诺附加这组心情。
- 旧页按“事件人数 × 2”写死的穗音信任表不再作为本事件专属结算表。观察、救济批次、拘捕和驱逐按实际处理人数记录，以 [事件目录](../incidents.md)、[访客代码](../../Source/Pawn/) 和 [穗音代码](../../Source/Storyteller/Suiyin/) 为准。本类没有独立穗音长链。
