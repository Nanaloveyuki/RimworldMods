# 游荡鼠族

## 来源场景

| 来源 ID | 场景 |
| --- | --- |

| I-009 | 游荡的野生幼年鼠族：单只来客，使用 WildChild 角色 |
| I-010 | 游荡的野生鼠群：人数随事件点数变化 |
| I-036 | 鼠疫游荡者：带鼠疫的 Wild 队伍，人数随事件点数变化 |

| I-009-01 | I-009 的原版野人子事件：单只幼年鼠族 |
| I-010-01 | I-010 的原版野人子事件：人数随点数及人数上限变化 |

八个来源共用类开关、生成权重和调试点数。五个访客来源另使用到达态度与长后续选择；未设置类态度时，其目录缺省均为中立，穗音下信任小于零时再降一档。三个原版野人子事件无派系，不使用访客态度。类内场景不会各占一份独立的抽取份额，抽取和配置规则见 [事件目录](../incidents.md)。

## 当前流程

I-008、I-009、I-010、I-036、I-041 从地图边缘入场，建立本模组访客 Lord，并按实际态度、角色闸门和赈灾区规则寻食。这五个来源的“野生”仍是来源角色，不表示原版野人。

- I-008、I-009、I-041 固定一人，点数不增加人数。I-010、I-036 按点数及人数上限生成队伍。
- I-009、I-041 使用幼年年龄规则，默认在 3 至 6.9 岁范围生成；启用幼年跟随全局年龄范围后可不同。不能把所有孤儿都写成刚出生的婴儿。
- 来客选择开启时，可以投喂、收留为短工、雇佣为长工、永久加入，也可以俘虏、奴役、攻击、送往合格盟友、拒绝或忽视。按钮能否执行仍看实际成员与相应闸门；奴役还需要 Ideology。投喂进入逐人交食等待，实际吃饱后才记 Fed。
- 拒绝、超时、驱逐和玩家伤害沿用到达态度规则；忽视只关闭选择信。不能按旧背景把所有未收留者都写成永久留在地图上。
- I-036、I-041 在鼠疫开启时实际带病；主事件信说明病情、治疗照料与传播风险，关闭鼠疫时说明健康到来。独立检疫节点、留观名单及康复回访已经退休，处置仍走原来客流程。

### 原版野人子事件

I-008-01、I-009-01、I-010-01 保留鼠族种族，将 PawnKind 切换为原版 `WildMan` 并清除派系。游荡、寻食、驯服、受伤和驯服失败反应由原版处理；成功加入玩家后由原版切换 PawnKind，种族不变。

- 原事件仍可抽取；子事件进入同一个“游荡鼠族”类，自然、广播和开发者触发共用现有入口。
- 三个子事件复用对应原事件的标题与叙述正文，发送普通通知信，不开本模组投喂、雇佣或直接加入的选择信。
- 不附加饥荒来源标记，不建立访客 Lord，不登记本模组救济、穗音案件或 ODF 后续。原版寻食不受本模组赈灾区闸门约束。
- I-008-01、I-009-01 固定一人；I-010-01 沿用 I-010 的点数人数与上限。生成沿用对应年龄设置，但幼年最低四岁、成人最低十二岁，避免生成无法自行游荡的婴儿。难度禁止儿童时不触发幼年子事件。
- 入场保留本模组温度限制，并检查原版适宜季节、有毒尘埃、毒雾和可用原派系条件。
- 世界队伍若被玩家远行队拦截，仍按共用拦截规则生成敌对穿图队伍；原版野人流程用于正常抵达家园或开发者直接触发。

## 后续

### 短后续

五个访客来源默认采用短后续。ODF 在短链阶段按 `followPredatorPercent` 掷一次捕食者到来，默认 10%；选中且本批仍有合格猎物时才排入到来事件，之后进入已处理阶段，不重复投掷。三个原版野人子事件不启动本模组后续。

即使打开本类长后续，I-008、I-009、I-010、I-036 也没有登记长链，仍使用短后续；只有 I-041 切换到下述互动链。长短链是所选入口，不保证先有捕食者再有长链。

### 长后续：I-041 不受待见的那一只

这条长链默认关闭，可以在“游荡鼠族”类设置中手动开启。它是 ODF 通用后续，不要求穗音，也不计作穗音专属 N 节点。

开启条件是原孤儿还活着、留在原地图并属于玩家，已不再是婴儿、能说话、没有医疗倒地，而且活动鼠疫已消失。记录若没有曾带病的标记，还要检查鼠疫免疫达到 100%。链使用这只原孩子；每个存档最多保留一条此身份声明。当前入口没有旧设计所说的“小概率王族”抽签，也不等到十四岁才首次开信。

孩子自称是某个鼠族王国不受待见的孩子，生病后被赶了出来。玩家可以：

| 选择 | 当前结果 |
| --- | --- |
| 承认 | 设置自认的头衔，心情 +6，15 天；之后遇到合格鼠族来客时会尝试谈论头衔，以实际闲聊互动推进 |
| 不承认 | 心情 −4，15 天，结案 |
| 追问 | 固定一次 50% 分支：坚持回去争位子，或承认称呼是在路上听来的 |
| 接受改口 | 心情 −2，15 天，结案 |
| 拒绝送回 | 心情 −4，15 天，结案 |
| 同意送回 | 三天后生成三名自称旧人的成年鼠族，玩家再决定让原孩子跟去或留下 |

旧人到场后：

- 交出原孩子：核对孩子与接收者、转移闸门和原地图，孩子改为接收者派系并离开，链结束。
- 留下：旧人离开，五天后生成三名携带粮食和钢刀的敌对鼠族，以攻击 Lord 报复。
- 来接的队伍或报复队伍已无可行动的接收者时，孩子获得 +8 心情，15 天，结案。原队伍在报复等待期被全部击败也会走这个结果。
- 玩家杀死认领者的判定优先于“队伍被打散”：固定一次 50% 害怕分支（−6，15 天）或认为暴力也是争位办法的分支（+4，15 天），随后结案。
- 原孩子被送走或死亡后不以另一只代替；链记录保留身份、已选分支和返访期限。医疗倒地暂停相应期限，婴儿年龄导致的不能行走不按医疗倒地处理。

### 角色触发

I-008、I-009、I-010、I-036 没有本来源专用的成年心情。I-041 的成年规则登记为：达到 `followAdultAge`（默认 14 岁）且恢复鼠疫标记成立时，普通角色各 50% 获得 −5 永久心情或 +3、15 天心情；善良固定负面永久，心理变态或食人者固定正面永久。普通负面分支还会尝试赋予善良特质，数值受 `followMoodScalePercent` 影响。

这条成年规则的“恢复鼠疫”目前读取 `!state.carriesPlague`，不是直接读已治愈的 Hediff；当前生成保存携带标记，未见康复后清除此标记的运行路径。因此不能承诺治愈后的 I-041 必然得到上述成年心情。它也与长链检查实际病情的开启条件不同。

## 实现依据与旧设计差异

本页合并原 I-009、I-010、I-036、I-041 及 I-041-01 的有效内容，并记录新增的三个原版野人子事件。人物身份声明、头衔交流、真实旧人、交接和报复已有实现；原文的稀有身份概率、独立检疫及“治愈即满足成年心情”不作为当前事实。原版野人驯服只适用于新增子事件。
