# 流民商队

## 来源场景

| 来源 ID | 场景 |
| --- | --- |
| I-012 | 流民商队：普通贸易来客 |
| I-038 | 鼠疫商队：同类贸易来客，在鼠疫开启时携带鼠疫 |

两条来源共用类开关、生成权重、到达态度设置、调试点数及长后续选择，属于同一个正池入口。两条目录缺省到达态度均为中立；穗音下信任小于零时再降一档。配置与抽取规则见 [事件目录](../incidents.md)。

## 当前流程

商队默认三人，不随事件点数增加：首人是 Trader，其余两人是 RatkinYoung。全批建立本模组访客 Lord，不再使用原版 `LordJob_TradeWithColony`。幼年随行者按实际年龄生成，不保证全是婴儿，也没有固定女性商人或商人与孩子的亲子关系。

非敌对商人开启原版交易接口，货物表补入同一访客 Lord 成员的背包实物。商人不卖食物；Lead Your Pet 不接管食物替代。下述长链要求真实已完成的购买标记，不把普通收留冒充买卖。

`traderIgnoresHarshEnvironment` 与 `traderIgnoresEnclosedSpace` 默认开启。分别关闭后恢复恶劣环境和不能到达地图边缘时的商队离场检查，仍由访客 Lord 执行，不因此改回原版交易 Lord。

I-038 保留真实鼠疫感染与传播；关闭鼠疫时不添加疾病。当前商队不在生成时打开整批选择信，不能承诺此路径必有追加病情说明的主信。独立 N-007 检疫、留观名单、检疫结果计数和康复回访已退休，不再另开检疫链。

## 后续

### 短后续

流民商队长后续默认开启。手动切换为短后续时，ODF 按 `followPredatorPercent` 掷一次捕食者到来，默认 10%；本批没有合格猎物时不生成，处理后不重复投掷。长链与短链是所选入口，默认长链不额外保证先触发捕食者。

### 长后续：不该在这批货里的一只

I-012 与 I-038 共用这条 ODF 通用互动链，不要求穗音。新配置和恢复默认均开启本类长后续；已有实例保留原期限和进度。

原批孩子中必须有一只还活着，留在原地图并属于玩家或成为殖民地奴隶，保存实际购买标记，而且已不再是婴儿、能够说话、没有医疗倒地。原版人物交易确实成交后，交易通知会为这两条来源的孩子写入购买标记。链只认原批身份，不生成另一只孩子代替。

满足条件后生成一件真实的 `RHAH_LongKeepsake`，放进孩子背包。当前没有旧设计所谓“偶尔带着小东西”的稀有开链概率；记物在长链开启时生成，不是到场时已携带的既定货物。

| 选择 | 当前结果 |
| --- | --- |
| 现在问 | 记录早问，发出当时回答，随后等成年 |
| 等成年后再问 | 保留东西，等 `followAdultAge`（默认 14 岁） |
| 收走东西 | 将同一物品从背包放到地图，孩子获得 −6 永久心情，归还可清除 |
| 归还东西 | 转回原孩子背包，清除 −6；成年前继续等待，成年后继续来历分支 |
| 丢掉东西 | 销毁真实记物，清掉收走产生的 −6，改为 −8 永久心情并结案 |

成年时若仍未归还，孩子不再说明来历；流程只保留归还选择，归还可清心情，但不会重开认领。记物在已开启链中被毁也会走丢失结果，不要求玩家按过“丢掉”按钮。

成年后听完来历，固定一次 50% 分支，三天后结算：

- 无人来：东西留在孩子身上，链结束。
- 有人来：生成一名真实成年鼠族，自称是孩子以前那个窝里的人。玩家可以让原孩子跟去，或把它留下。
- 让它跟去：实时核对原孩子、接收者与转移闸门，变更派系并离场；买下后仍为殖民地奴隶的孩子也有专门交接路径。不能行走的孩子由合格成人携出。链结束。
- 留下：来客尝试一次实际辱骂后离开，最多留一天；以后合格鼠族来客也可参与“卖剩下的”辱骂互动。这是持续等来客的社交阶段，不是又一次认领或报复队伍。
- 玩家杀死认领者：固定一次 50% 害怕（−6，15 天）或松一口气（+4，15 天）的心情分支，结案。认领者已经失去行动能力而没有玩家击杀时，不伪造这个击杀分支。
- 原孩子被送走或死亡后不换人续链；医疗倒地暂停相应期限。身份、物品、选择、固定分支、期限及已离场名单都留在 `longFollows`。

### 角色触发

I-012 来源且带实际购买标记的角色，在生日检查达到 `followAdultAge` 时，普通角色各 50% 获得 −5 或 +4 心情，均为 15 天；善良固定负面永久，心理变态或食人者固定正面永久。普通负面分支还会尝试赋予善良特质；数值受 `followMoodScalePercent` 影响。只有规则实际应用后才记去重标记。I-038 共享认领长链，但成年规则没有对应的出售心情分支，不能直接复制 I-012 的效果。

旧 I-038 设计的“把病传给殖民者，殖民者病好后获得 −4、15 天心情”目前只有 `OnTraderPlague` 规则和 ThoughtDef。传播路径会记录商队在场时的传播标记，但未接入殖民者康复后调用这条规则的运行入口，不能写成已落地的恢复结果。

## 原设计与实现差异

本页吸收 I-012-01 与 I-038。原认领、记物收走与归还、毁物心情及后续辱骂已经实现；商队三人访客 Lord、鼠疫同类长链是现行规则。

旧设计中“牵着鼠蛋，把鼠蛋设为囚犯出售”的过程没有在当前到达路径落地：随行幼年成员未在此处设置为囚犯，补充货物表也没有直接把这些成员列为商品。因此不能承诺到场必定能买下两只随行孩子。稀有记物概率、鼠疫传播后的康复心情也不作为当前承诺。
