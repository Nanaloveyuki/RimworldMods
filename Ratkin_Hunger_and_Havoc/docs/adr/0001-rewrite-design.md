# ADR 0001：独立重写，而非 Continued 移植

## 背景

旧鼠灾把生成来源、访客行为和叙事身份绑在经历上；经历变更会丢失身份，角色又依赖大量空标签 Hediff。事件和剧情共用编号，外部模组只能猜经历或补私有实现。直接移植会把这些耦合、旧存档格式和内部命名一起带入新项目。

## 决策与理由

- 独立包重新实现玩法，旧仓库只用于行为对照。新包不替换旧包、不迁移旧鼠灾存档；冲突时由独立 Guard 提示并阻止主体加载，而不是自动停用旧包
- 区分种族、来源、活跃访客、角色和经历。经历只承载内容，不承担来源判定；来源标记跟随 Pawn，永久身份转换后仍能保留历史事实
- 身份采用 Hediff + Comp，不向种族 ThingDef 挂身份 ThingComp，避免与 NewRatkinPlus / HAR 的种族补丁争夺载体。对外边界进一步由 [ADR 0002](0002-pawn-mod-compatibility.md) 和 [ADR 0003](0003-engineering-standards.md) 明确
- 事件与剧情使用不同的稳定显示 ID，显示 ID 不等于列表位置；Def 使用可读名字。这样重组设置和同类事件时，不需要重写已有来源身份
- 访客行为通过闸门协作，生成变体共用行为实现；避免外部模组依赖私有 Job、Comp 或复制角色规则
- 游戏内容按版本目录组织，跨版本资源与源码不随版本目录重复复制

## 后果

旧存档继续依赖旧包，不能因启用新包而自动转换。新项目承担自己的公开 API、存档兼容与卸载归属，不沿用旧项目内部类型作为合约。

本文保留重写决策及理由，不维护目录树、字段表、生成步骤、事件编号对照或已完成里程碑。当前约束以根及就近 `AGENTS.md` 为准；实现、配置和公开签名直接读源码、Def 与项目文件。后续设计取舍由相关 ADR 记录，工作项由 GitHub Issues 跟踪。
