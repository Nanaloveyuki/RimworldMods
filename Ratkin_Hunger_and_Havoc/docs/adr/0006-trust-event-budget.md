# ADR 0006：逐人信任与事件额度

逐人结算保留，便于区分同批人物死亡、失踪和离开的实际结果；同一事件及其后续的正向累计最多 +5、负向累计最多 −5，分别累计，不靠正负抵消或重复操作恢复额度。统一负向上限也覆盖玩家直接杀死，替代 [ADR 0004](0004-relief-and-endings.md) 每批 −10 的数值规则，但保留玩家暴力令救济批次失败、自然死亡不扣分、未知去向不当成功的边界。作者随后确认普通事件结局废弃，信任只作事件干涉因素，不再保留普通结局门槛。具体结算与基础分值见 [机制记录](../kingdom-arc/mechanics.md)，事件额度尚未实现，旧结局运行代码尚未移除
