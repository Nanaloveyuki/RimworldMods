## 叙事方向

从穗音寝室的一页日记开始。童年里，她牵着父亲去御花园，捧起一只蝴蝶，问所有鼠是不是都能这样玩。长大后，她翻过宫墙，才看见那句回答没有包括的人。

玩家先认识她的父亲、她受过的教育、她曾经相信的生活，再看到她的动摇。兰迪在她第二次走进平民区时伸手；“超凡智能”沿用背景故事中的说法，暂不解释其本体。

穗音是王庭里善良、乐意改变现状的既得利益者。她不愿接受墙外的悲惨生活，有愤青式的不满，也带着宫廷教育形成的先入判断，缺乏持续的实地走访。她想主动改变王国，却依恋父母、宫廷生活和自己的身份，遇到涉及这些利益的事情会犹豫。

作品方向参考《红与黑》（音乐剧）与《是，首相》：她在宫斗、官斗和不同利益的交涉中逐渐了解事实、积累政治经验。核对粮食回执是她第一次尝试介入，不是整部故事的主题。人物的说法、动机和实际发生的事需要分开；她在新稿中断言“一定有鼠在暗渡陈仓”，这是她的判断，不是叙事预先确认的真相。

K1～K5 先交代她从哪里来、为何求助，以及玩家如何通过初次合作成为她愿意倾诉的人；不默认亲密或恋爱，也不新增关系分数。后续成长与最终政治分歧留到 K6 之后，具体篇幅和节点尚未设计。

## 与原有事件的关系

- `I-001` 到 `I-051` 照常运行。王国篇不占用它们的抽取机会，不改它们的来客、奖励、后续或结果。
- 已有穗音 `N-` 节点也不被改名后搬进主线；粮洞、食物换情报、旧记录箱和普通资助都不是本篇入口。
- 开启王国篇不要求完成普通饥荒事件，不累计它们来解锁章节，也不把它们的死亡、救济或交易转算成主线成绩。
- 日历、地图通行、实际物资交付等基础能力可以共用；案件、角色身份和剧情事实分别保存。
- 普通事件可以自然打断玩家安排，但不是每一幕安排的“必遇灾难”，兰迪也不保证每次善举后都发生坏事。

现有公文、书记、配给厅、使者与护粮安排可作为早期经历的素材，但不能只给原来的求食、交易、认亲事件换上宫廷称呼。每个场景要说明她想办什么、对方为何答应或推诿、她因此发现了什么；普通事实通知不必扩成独立人物支线。

## 五个远期结局

以下为作者确认的规划方向，均不在 K1～K5 触发。具体选择链、条件、优先级与演出尚未设计，不新增 Def、翻译键或存档字段。

| 结局 | 人物与政治结果 |
| --- | --- |
| 温和的改良 | 玩家帮助穗音取得最终权力；她受王国体制约束，向官僚与贵族妥协，各退一步。底层不至于活不下去，也没有过上很好的生活 |
| 激进的斗争 | 玩家支持穗音走上鼠族游击队的道路，与游击队推翻王国，建立鼠托邦 |
| 失败的反抗 | 即使得到玩家帮助，她仍未取得权力；矛盾的思想和犹豫使她错失良机，最终永久囚禁在宫中，成为“金丝雀” |
| 永久的沉睡 | 搜集信息、筹划夺权或斗争时泄露消息，被王室以保护名义囚禁；仍继续行动，再次被发现，最终被“自愿的”赐毒而亡 |
| 癫狂的世界 | 大量互相冲突的信息伴随自我闭塞、压抑与癫狂，最终被送入疯鼠院；具体剧情因果尚未确定 |

不能把一次补发成功等同于温和改良，把寄出材料等同于革命，或把书记死亡等同于穗音的终局。结局应由后续玩家选择与实际经历形成；“癫狂的世界”尚无完整因果，不先补成隐藏理智值或随机坏结局。

## 呈现

回忆采用连续画卷：一幅画可以承载几句对白，换句不必换画。`tmp.md` 中两秒切句与一秒半动作镜头保留为作者节奏参考；具体阅读控制见 [插图与 Letter](presentation.md)。

剧情回忆、私人信和结局使用全屏画卷；赴约、公函、交付与期限使用带插图的行动信件，正文说明来意，条件、代价和定位单独列明，底部保留玩家选项。事件到达时先进入信件列表，打开后阅读，不在战斗中强行播放长篇。关键回忆可由行动信件打开画卷，再返回原信作决定

每个事件文件都包含流程、分支、状态、文案与插图安排；文案中的条件版本只在对应事实成立时使用。

## 编号与事实边界

`Kx-Ex` 是本设计内部的章节编号，尚未注册为 Def 或 ODF definition。原来的 `I-`、`N-` 编号继续归原系统所有。

穗音是受过宫廷教育的王国公主，人物方向以上述政治剧总纲为准。红发男人是兰迪；不据此把他写成鼠神、饥荒元凶或超凡智能本体。鼠神的真伪、鼠族起源和帝国是否出兵仍留白；游击队推翻王国只属于“激进的斗争”规划，不预先写成所有路线必然发生的事实。

王国公文、书记与配给厅均为本篇新增提案，不宣称是 NewRatkinPlus 原设定。王室、领主、军队、教会与运输人员可能有不同利益；粮食短缺的责任随调查逐步显现，不在开头指定唯一罪犯。
