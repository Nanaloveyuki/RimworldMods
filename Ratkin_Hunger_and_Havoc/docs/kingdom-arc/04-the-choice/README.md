## 演出与延时

一次只执行一项行动，邀请手动阅读；交接一秒半，成功确认两秒。暂缓日记五秒、六秒，选择处停止推进。行动窗口七个游戏日，逐件明确。

## 流程与分支

行动进行中不得并发另一项行动。行动结束记录实际结果，进入第五幕阶段回信；受挫后可重新考虑仍可行的行动。暂缓无隐含倒计时，材料失效与主动暂停均不触发全篇坏结局或开放结局，不锁定最终政治立场。
