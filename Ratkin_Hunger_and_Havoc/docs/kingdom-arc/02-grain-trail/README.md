## 叙事

穗音尝试用宫廷里学过的礼节和公文办事。两份回执引出被撤职的书记，玩家赴配给厅核验；文书差异、证词和看过原簿分别保留。这是她第一次借玩家的帮助检验自己的判断；调查不预先证明她认定的贪腐，也不要求她此时已经掌握政治经验。

## 演出与延时

来信和谈话手动阅读；递函、进厅动作一秒半，翻簿0.6秒。收束日记六秒一段，赴约期限七个游戏日单独列明。

## 流程与分支

收到副本才记录持有。停止调查直接接本幕收束；核验拒绝、错过或未能安排也有终态，不需要原有粮洞或记录箱事件。

所有事件使用本篇独立案件和人物。普通 RHAH 事件一直照常运行，既不替代本篇任务，也不累计为章节解锁条件。美术按各文件末尾构图需求绘制，尚未得到的物件、已经离开的角色不能出现在成功画面中。
