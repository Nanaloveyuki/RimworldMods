# 全局运行时与卸载

- 新增全局组件前明确职责、生命周期和持久化范围，优先复用已有 Game/Map 组件，避免第二套全局状态拥有者
- 设置保存用户输入，具体行为求值留对应领域；设置窗口的按钮调用领域入口，不在绘制或设置持久化中执行事件调度与角色状态转换
- 卸载导出先备份原当前状态，再停用新内容，只清理序列化副本；不清 live runtime，不覆盖原存档
- 清理只执行已确认归属的 Remove/Replace；未知类型、缺少替代项或残留引用使导出失败，不能按前缀猜删后宣称安全
- ODF 框架状态不属于本模组；导出只移除本 provider 分区，保留根组件、schema、meta 和其它 provider 分区
