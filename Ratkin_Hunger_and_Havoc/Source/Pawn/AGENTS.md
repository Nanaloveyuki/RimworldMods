# 访客行为边界

- 行为入口查询 API 对应闸门，角色或设置不能代替闸门；JobGiver 不复制身份层的优先级和默认角色规则
- 无 Lord 回退与批次反应只处理无 Lord 或自有访客 Lord 的活跃来客，不接管原版袭击、偷窃、绑架 Lord 或自有拦截批次
- 点击投喂、预留、搬运和交货都不算吃饱；只有实际进食达到阈值才结算访客 Fed，临时玩家成员的进食不改停留期限
- 食物交接按实际接收者分别记账和检查截止，不用同 Lord 其它人的在途数量扣本人需求，不因一人收齐结束其它人的等待
- 倒地成员和被抱持孩子仍属于照护关系；部分处置只改变实际合格成员，永久释放清职责并停访客 Job，保留来源
- 雇工到期恢复访客身份并拒绝新的普通工作；医疗倒地暂停期限，单纯年龄不能行走不暂停，也不强行制造离图 Job
- 衣物解锁只撤销本模组本次停留登记的锁，不清除其它来源的衣物锁
- 携带与放下同时核对关系引用和真实 carry 容器；实际放下成功才记弃养并移出照护 Lord，失败不能凭 holder 引用写成功记录
