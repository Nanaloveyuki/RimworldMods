# 源码约束

- 实现类型默认 `internal`；Verse、XML 或存档反射确需 `public` 时保留入口并说明原因，公开可见不等于稳定 API
- 标识符用英语，文件名与主类型一致；沿用 `RHAH_` 及原版扩展点的命名形式，一个文件一个主概念，相关枚举可同文件
- 类型、方法、属性、事件、枚举、常量及 DTO 公开成员用 PascalCase；接口加 `I`，字段、局部变量和参数用 camelCase，不加 `_` 或 `m_`
- 沿用 Allman 括号、显式类型和块命名空间；必要注释用短中文、句末无标点，只说明意图、约束或非显然事实，不另设 XML Doc、nullable 或风格工具前置要求
- 路径与命名空间对应实际领域职责；有第一个类型才建目录，不另建 `Behavior`、`Settings` 或 `UI` 层，设置数据留 Core，求值和绘制留各自领域及适配边界
- 方法保留单一主要责任；同一状态事务的校验、提交和通知可放一起，不新增承载多个领域决策的万能 Utility
- 新存档键用 camelCase，字段初值与 Scribe 默认值一致；定义 null 与空集合的区别，载入后补齐必要集合，计算状态用属性而非额外存档
- Tick、高频 Pawn/Map/Job 查询避免 LINQ、闭包、装箱、重复拼串和临时集合；优先事件通知，没有事件入口的慢状态按游戏内小时检查，不用高频扫图或寻路代替
- Harmony 默认只补原版或种族框架的明确缺口，优先 Prefix/Postfix；跨模组补丁例外在相关 ADR 说明目标、理由、加载顺序、兼容范围和失败策略，Transpiler 说明更小补丁不可行的原因
- 跨模组协作消费稳定公开 API，不把私有字段、反射路径或 XML 实现细节当合约；反射公开 API 时核对类型、签名和前提，失败给诊断并按依赖边界停止或跳过，不静默绕过限制
