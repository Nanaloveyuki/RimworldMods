# 事件链边界

- ODF 是事件链唯一定时与实例持久化运行时；本层提供定义、脚本、动作和迁移，具体角色、物件及地图事实仍由所属领域持有，不增设双时钟或扫描引擎
- 旧档记录仅作迁移输入与失败保留，不能执行；迁移保持既有实例身份、阶段、时刻、期限、payload 和结局，不重抽随机结果
- 迁移整批原子导入，连同待到达记录一起验证；非法或未知输入保留原数据、暂停并诊断，不修正或丢弃部分记录后继续
- 已存在 provider 分区优先，显式空分区也不重复导入；失败诊断分区不代表成功，继续保留旧输入，只有成功才清旧数据
- provider 注册、迁移准备及异步地图生成的到达请求切回 Unity 主线程；引用解析和注册完成后才激活，不因初始化期间暂非 Playing 丢失请求
- Prepare 校验并缓存类型化事实，Tick 不重复解析；已提交的不确定动作保存凭据，读档不重放，终态或已完成的休眠实例不重新解释活动 payload
- 未完成初始化或迁移时不启用旧引擎回退，保存保留旧输入和失败诊断；合法地图标识不得被当成未设置哨兵，计时溢出不得回绕成立即执行
