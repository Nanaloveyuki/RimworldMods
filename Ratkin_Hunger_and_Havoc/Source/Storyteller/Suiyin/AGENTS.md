# 穗音与王国主线

- 王国案件事实与普通来客信任、既有剧情节点分开记录；不能用普通信任增减或单一进度整数代替案件证据和分支事实
- 已有关键人物死亡、失联或不可用时保留真实结果，不补造替代人物来推进；首次创建与已有引用丢失必须区分
- 私下陈述、署名公开和安全转移的同意分别处理；玩家点击不能代替当事人同意，囚禁或奴役不能当作同意保护
- 文书和粮食按实物持有与交接记账；接收者真实收到才计交付，失败回退物件，不以选项、预留或计时结束冒充成功
- 已确认的材料、接收结果、人物状态及失败原因保留独立事实；延续或重试路线不撤销先前真实交付，也不重新抽取旧结果
- 操作提交时重新核对阶段、版本、参与者资格和实物，不让过期窗口或选择信覆盖新的案件状态
- 已退休结局只兼容存读历史状态，不恢复判定、触发入口或设置消费；王国主线不借用退休结局充当普通事件奖励
