# 生成边界

- 请求先验证再生成；失败返回明确失败结果，不补造另一种角色、换目标地图或重跑可能已产生部分角色的整批请求
- 显式生成配置彼此独立，只修改调用方启用的项目；显式空值与未指定有不同语义，缺失或不允许的显式异种不能偷偷换成其它异种
- 异种选择尊重 HAR 公开许可，强制请求和关闭生成优化都不能绕过；许可 API 不可用或查询异常时停止生成，不复制白名单规则
- 生成后核对实际种族、异种及基因归属；验证失败销毁新角色，不登记来源、不入场、不追加自有基因来掩盖失败，合法冲突抑制不等于基因缺失
- 默认普通衣池只取代码中的原始固定名称与既定来源交集，原版衣限官方 Core/DLC 来源、鼠族衣限指定上游来源；不读第三方扩大的 HAR 可穿池，不增加 opt-in 扩池，温度衣不能成为跳过普通衣的理由，显式衣物请求保留调用方行为
- 先完成整批生成与家庭关系绑定，再交给访客层建立照护 Lord；经历和特质抽取不决定来源身份
